# HashTag Network

Démo d'un registre partagé (inspiré d'Hyperledger Fabric) qui prouve qui avait une valise à chaque passage en correspondance, plus le dossier projet du groupe.

Projet de groupe, cours Blockchain & Web3, emlyon business school.

- `index.html` : l'application complète (un seul fichier)
- `supabase.sql` : la table qui stocke la partie Projet, partagée entre les membres

La partie Projet lit et écrit dans Supabase avec la clé publique. Toute personne qui a le lien du site peut la modifier.
